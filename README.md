# Оценка общественного отклика на новости о Китае в японских СМИ

Финальный проект по программе ДПО "Компьютерная лингвистика" (НИУ "Высшая школа экономики").

Автор: Коростелева Мария Олеговна.

## Цель

Оценить, какие новости о Китае вызывают общественный резонанс в Японии, а также построить модели для предсказания реакции японской аудитории на те или иные новости. В рамках данной работы общественный отклик оценивается по количеству комментариев к новостям.
